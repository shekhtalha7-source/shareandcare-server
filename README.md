# ShareAndCare Server

Backend server for the ShareAndCare community events platform.
Built with Node.js, Express and MongoDB.


## API Endpoints

- POST /add-event : Create a new event
- GET /events : Get all events


## Setup

1. Run `npm install`
2. Create a `.env` file using `.env.example`
3. Run `npm start`


## Tech Stack

- Node.js
- Express
- MongoDB
- JWT authentication
- Vercel (deployment)
